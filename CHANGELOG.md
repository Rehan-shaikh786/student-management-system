# Changelog

All notable changes to the Student Management System are documented here.

## [1.0.0] - 2026

### Added

- Student CRUD operations
- Course CRUD operations
- Enrollment management
- MySQL database integration
- Spring Data JPA
- Input validation
- Global exception handling
- User registration
- User login
- BCrypt password encryption
- JWT authentication
- USER and ADMIN role-based authorization
- 401 Unauthorized handling
- 403 Forbidden handling
- Swagger / OpenAPI documentation
- Externalized database password configuration
- Externalized JWT secret configuration
- README documentation
- Project screenshots
- MIT License
- Contribution guidelines

### Security

- Passwords are stored using BCrypt hashing.
- JWT is used for stateless authentication.
- Protected APIs require authentication.
- Administrative operations require the ADMIN role.
- Database credentials and JWT secrets are externalized.

### Documentation

- Added API documentation with Swagger UI.
- Added project architecture and API information to README.
- Added project roadmap.
- Added contribution guidelines.
