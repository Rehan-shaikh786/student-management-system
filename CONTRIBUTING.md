# Contributing to Student Management System

Thank you for your interest in contributing to this project.

## How to Contribute

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your changes.
4. Make your changes.
5. Test the application.
6. Commit your changes with a clear commit message.
7. Push your branch.
8. Create a Pull Request.

## Development Guidelines

- Follow standard Java naming conventions.
- Keep the existing package structure.
- Write clean and readable code.
- Avoid committing passwords, JWT secrets, or other sensitive information.
- Test changes before creating a Pull Request.
- Update the README when adding major features.

## Commit Messages

Use clear commit messages, for example:

```text
Add student search API
Fix JWT authentication issue
Improve Swagger documentation
Update README
